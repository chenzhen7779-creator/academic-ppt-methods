# Academic Review Checklist

Use this checklist before finalizing any page or figure.

## A. Consistency
- Does the slide match the proposal exactly?
- Are variable names consistent across slides?
- Are primary / secondary / exploratory labels consistent?
- Are scoring ranges and instrument names accurate?

## B. Boundary control
- Any accidental causal wording in a cross-sectional or observational design?
- Any simulated plot shown as if it were empirical data?
- Any technical parameter stated too confidently when still pending validation?
- Any path diagram that needs a “not causal mediation” note?

## C. Redundancy
- Is figure text being repeated outside the figure?
- Can outside text be reduced to 1 focus line + 1–3 bullets?
- Is the slide readable within 15 seconds?

## D. Defense usability
- Can the presenter explain the slide in 20–40 seconds?
- Is there a clear take-home message?
- Is the audience guided toward the most important element?

## E. Statistical rigor
- Are model comparisons described on the same sample and covariate base?
- Is the correction method for multiple testing stated when needed?
- Are effect sizes / confidence intervals prioritized over significance-only wording?
- Are exploratory analyses explicitly labeled?
