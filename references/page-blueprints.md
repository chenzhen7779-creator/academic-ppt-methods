# Page Blueprints

Use these as defaults, then adapt to the user's actual study.

## 5.1 Research design / participants
Best for:
- study type
- participants / inclusion window
- sample target
- recruitment logic

Outside-figure text should emphasize:
- study design label
- key inclusion criteria
- recruitment or sample cap
- one sentence on why sample size is appropriate if available

## 5.2 Variable and measurement framework
Best for:
- explanatory variable(s)
- outcome(s)
- covariates
- scoring ranges
- primary / secondary role labels

Outside-figure text should emphasize:
- no artificial composite score unless predefined
- which outcome is primary
- which variables are only descriptive / sensitivity material

## 5.3 Task / experiment procedure
Best for:
- stimulus / task logic
- trial flow
- threshold formation / scoring rule
- schematic apparatus or response rule

Outside-figure text should emphasize:
- schematic nature of the task figure
- technical parameters not yet frozen, if applicable
- the meaning of the derived index

## 5.4 Functional / behavioral measures
Best for:
- multi-component scales such as SPPB
- objective motion capture / gait metrics
- scoring formulas and valid-trial rules

Outside-figure text should emphasize:
- how the indicator should and should not be interpreted
- whether the measure is core, supplementary, or exploratory

## 5.5 Procedure and quality control
Best for:
- order of testing
- approximate timing
- pilot / calibration / retest / replacement rules
- safety and blinding arrangements

Outside-figure text should emphasize:
- estimated time is a plan, not already observed fact
- who is blinded to what
- safety / withdrawal / protection procedures

## 5.6 Research questions and analysis strategy
Best for:
- decomposition of questions into blocks
- candidate association forms
- exploratory path diagrams

Outside-figure text should emphasize:
- which question is primary
- which diagrams are schematic, not results
- cross-sectional designs do not justify causal interpretation

## 5.7 Statistical models and hierarchy
Best for:
- main model equation
- nested comparison logic
- family-wise correction plan
- primary / secondary / exploratory hierarchy

Outside-figure text should emphasize:
- same-sample nested comparison principle
- report estimates and 95% CI
- exploratory analyses are not upgraded to main findings

## 5.8 Technical route / implementation flow
Best for:
- preparation → recruitment → testing → QC → analysis → reporting

Outside-figure text should emphasize:
- arrows show workflow, not causal direction
- QC贯穿全流程
- output interpretation boundaries
